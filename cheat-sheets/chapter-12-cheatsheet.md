# Chapter 12 Cheat Sheet — Exam Simulation & Time Management

## Core Pacing Numbers
| Metric | Value |
|---|---|
| Total questions | 70 |
| Total time | 120 minutes |
| Raw average (no buffer) | ~1.71 min/question |
| Recommended target pace | 1.5 min/question |
| Resulting review buffer | ~15 minutes |

## Pacing Checkpoints
| Question # | Elapsed time target |
|---|---|
| 25 | ~37–40 min |
| 50 | ~75 min |
| 70 (first pass done) | ~105 min |
| Final review window | last ~15 min |

If behind pace at any checkpoint: flag more aggressively rather than slowing further — protect the review buffer.

## Flag-and-Return Rules
- Answer with best guess, THEN flag if uncertain — never leave blank.
- Never stop mid-exam to resolve a flag; keep forward momentum.
- Use remaining buffer time exclusively for flagged items.

## Domain-Weighted Review Priority
1. Pull up the official exam guide's domain weight table before exam day.
2. During review buffer, resolve flags in **highest-weighted domains first**.
3. Move to moderate-weight domains next, then lightly-weighted domains only if time remains.
4. Rationale: fixing an error in a heavy domain has more score impact per minute than in a light domain.

## Recurring Trap Patterns to Watch For
- Option that's "technically correct but requires an extra unstated step" → usually wrong.
- Deprecated/legacy service named as an option → usually wrong.
- Overly complex/expensive solution when a simpler one meets all stated requirements → usually wrong.
- Use pattern recognition as a **tiebreaker only**, not a replacement for domain knowledge.

## Final Pre-Exam Review Strategy
- Do a **high-level pass across all seven domains** — not a single deep dive.
- Weight review time toward the highest-weighted domains, but touch every domain briefly.
- Avoid re-reading full transcripts; focus on numbers, limits, comparisons, and known gotchas.

## Certiverse Remote-Proctoring Checklist
| Requirement | Detail |
|---|---|
| Check-in | Complete required ID and system check before scheduled start |
| Room scan | Webcam scan of desk and surrounding area — must be clear of notes, phones, extra devices |
| Monitors | Single monitor only; secondary displays not permitted, even if off |
| Materials | No personal scratch paper; only proctor/platform-provided tools allowed |
| Environment | Quiet, private room; no other people entering during the session |

## One-Line Strategy Summary
Pace at 1.5 min/question → bank ~15 min buffer → flag uncertain answers → review buffer time domain-weight-first → watch for recurring trap patterns → arrive proctor-ready with a clean, scanned environment.
